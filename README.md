# Ici je t'explique

Vidéos explicatives animées sur le gaming et le streaming : format vertical 1080x1920, 45-60 s, avec voix off, texte animé, sous-titres, illustrations et mini-vidéos d'exemple.

- `.claude/skills/ici-je-t-explique/` : l'agent qui crée les vidéos (instructions, banque d'idées, moteur de rendu).
- `videos/` : les vidéos terminées, `AAAA-MM-JJ_<Sujet>.mp4`.
- `explications/` : le script (`scenes.json`), la voix et la légende de chaque vidéo, pour pouvoir la refaire.

Une nouvelle vidéo est créée automatiquement tous les jours vers 5 h (heure de Paris).

Lien direct d'une vidéo : `https://raw.githubusercontent.com/itsklyzen-hub/ici-je-t-explique/main/videos/<fichier>`
